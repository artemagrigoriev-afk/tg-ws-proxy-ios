# TG WS Proxy - iOS

Русский | [English](./README.md)

Порт [python-проекта Flowseal TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) на iOS

iOS приложение (iOS 14+, SwiftUI) разворачивает localhost MTProto-прокси, который перенаправляет трафик с мессенджера через WebSocket на сервера Телеграм

## Принцип работы

Приложение не использует VPN и Packet Tunnel Provider для работы MTProto прокси - оно запускается в контексте работы приложения

Чтобы iOS при сворачивании приложения не усыпляло/закрывало его, реализовано бесконечное воспроизведение беззвучного аудио, пока работает прокси. При этом можно слушать обычные треки, так как аудио-сессия инициализирована с параметром mixWithOthers

**P.S.** Способ с фоновым обновлением гео был отброшен по причине повышенного расхода заряда аккумулятора. Другие фичи из Background Modes capability плохо подходили под задачу

Само прокси работает по тому же принципу, который реализован в оригинальном репозитории

**Примечание**: Данное решение не позволит приложению пройти релизное ревью в App Store, но вполне сможет пройти проверку на публичное тестирование в TestFlight

### Автоматизация

Так как для работы приложения в фоне так или иначе необходимо использовать один из background modes, затраты на аккумулятор все равно будут высокими. Поэтому чтобы минимизировать затраты энергии в приложение были добавлены шорткаты:

- Запуск Telegram WS Proxy через foreground (С запуском приложения)
- Запуск Telegram WS Proxy через background (Без запуска приложения)
- Остановка Telegram WS Proxy

С помощью данных шорткатов можно завести автоматизации на запуск прокси при открытии телеграм и остановку при сворачивании/закрытии приложения

**Пример алгоритма автоматизации при открытии приложения Telegram в быстрых командах**

```
1. Запустить Telegram WS Proxy через background
2. Получить статус выполнения операции (true/false)
- Если прокси запустился (true), завершить выполнение шортката
- Если прокси не запустился (false - такое иногда бывает для AudioPlaybackIntent'ов, что iOS требует состояния запущенного приложения), то продолжить выполнение шортката
3. Запустить Telegram WS Proxy через foreground. В случае успеха запустится приложение TgWsProxy
4. Получить статус выполнения операции (true/false)
- Если прокси запустился (true), запустить обратно телеграм, чтобы вернуть мессенджер обратно
```

**Алгоритм автоматизации при сворачивании/закрытии приложения Telegram в быстрых настройках** примитивный: достаточно использовать базовую команду из приложения *Остановка Telegram WS Proxy*

## Применение

Настройки по умолчанию позволяют запустить прокси при первом запуске без предварительной настройки. Сервер будет слушать *127.0.0.1:1443*

MTProto-секрет для подключения генерируется рандомно в первый раз

Через настройки изменить параметры работы прокси

**Примечание**: В настройках сервера и для подключения клиента секреты различаются (дополнительный первый байт dd) - это нормально. Первый байт - это опциональная настройка для работы MTProto прокси:

- **Нет первого байта** - работа в режиме plain
- **dd** означает работу с обфускацией пакетов (split)
- **ee** означает работу в режиме маскировки под обычный HTTPS. **Данный режим не поддерживается текущей реализацией**

## Сборка

Возможны варианты сборки приложения:

1. Сборка через бесплатный Apple Developer аккаунт - идеально для личных устройств. Apple подписывает приложение на 7 дней, после необходимо пересобирать и переподписывать приложение
2. Дистрибуция через TestFlight - требуется мак и учетная запись с купленной лицензией разработчика. Самый оптимальный способ, так как устанавливать приложение уже может любой, у кого есть ссылка на публичное тестирование, и срок жизни загруженной сборки 90 дней
3. Сборка неподписанного приложения (Jailbreak или Sideload)
```
chmod +x xcodebuild_unsigned.sh
./xcodebuild_unsigned.sh
```
